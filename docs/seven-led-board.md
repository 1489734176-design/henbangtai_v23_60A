## 扫描及方向联锁

TIM1 每个 PWM 周期调用一次扫描。前7槽扫描各灯，第8槽熄灭矩阵并将 PB8/PA14 设为上拉输入，第9槽读取方向和按键。16kHz PWM 下，输入稳定时间为62.5us，完整扫描周期为562.5us。

每次切灯先断开两路阳极，再拉高全部公共阴极，最后驱动选中行列。输入任务只读窗口采样缓存。没有任何灯脚与 ADC 共用，因此不保留参考程序中多余的 ADC 复用空窗。

上电先确认扳机，再去抖方向。运行中换向先撤销运行许可，电机停稳并松开扳机后才更新方向；所有停止到运行的路径都检查方向有效和重扣锁定，包括原有制动续启路径。

## 报警次数

三个电量灯同步报警，沿用参考的灭500ms / 亮约200ms、一组结束间隔1500ms、每次调度10组的节奏。扳机松开后回到正常电量显示。

| 次数 | 故障 |
|---|---|
| 1 | 硬件过流 `gIBusAcmpOCP` |
| 2 | 电池温度（编号保留，本版检测不启用） |
| 3 | MOS 过温或热过载 |
| 4 | 堵转 |
| 5 | 软件峰值过流、一级/二级/三级平均过流 |
| 6 | 待机/运行欠压 |
| 7 | 飞钻 |
| 8 | 过压 |
| 9 | MOS 上/下桥臂异常 |
| 10 | 缺相 |
| 11 | 失步 |
| 12 | 电池通信（编号保留，新板无此电路） |
| 13 | 四级平均过流 `gIBusAvgOCP4` |
| 14 | 其他未分类故障 |

1～12 的编号和判定优先级与参考程序一致；参考的兜底13次顺延为14次。独立照明保持原有正常松手10s熄灭、故障按住30s熄灭、故障松手立即熄灭的延时规则，故障码由矩阵电量灯显示。

## 配置变更

- `LED_SCAN_EN`: 0 → 1。
- `BAT_COM_EN`: 1 → 0。PA11/12/14 已分配给新板 EN/照明/KEY，不得直接重新启用旧板通信配置。
- `EN_BAT_TEMP_DETECT`: 1 → 0，按用户要求将 DS/TBAT 作为预留接口。
- `MOS_NTC_10K_3435K`: 1 → 0；`MOS_NTC_100K_3950K`: 0 → 1。
- `MOS_TEMP_UP_RES`: 10K → 4.7K；95℃保护、85℃恢复的温度目标保持不变，使用工程已有100K/B3950阻值表重新计算 ADC 阈值。
